# s25-league (build 2026-10-30s25): League site Bets

Base: s24-league. Stage only.

1. **Only the creator settles (new actions only).** Who-won buttons are shown only to the manager who placed the bet. Everyone else sees "Only <name> (who placed it) can settle this bet." The handler refuses anyone else.
   - Every event this version writes carries a version marker `v:25`.
   - A marked settle counts only from the creator.
   - **Old bets are never reopened:** a settle without the marker was written before s25 and keeps exactly the s24 rule, including a report from the other manager (agree → settled, different answers → disagreement, a lone report settles by itself after 48 h).
   - "Old" is decided by the marker and by the order of each manager's own log, never by the clock alone. An unmarked settle that comes after a marked event in the same log can't be from before s25, so it is ignored. So is an unmarked settle on a bet placed by s25 code.
   - Fix result stays two-sided.
2. **Save race.** After each save the page waits a moment and reads again. If another phone's save wiped my event, it adds it back and checks again. The page shows "Saving…" until the read-back confirms, then "Placed!". If it can't confirm, it shows an error and nothing is reported as saved.
3. **Reading the bet.** Clear bets are read: A beats B, margins, over/under. The confirm step says "We read this as: …"; ← Change edits it. Anything unclear stays manual.
4. **Proposed result.** After the final, the creator's page reads the public college scoreboard (read only) and shows "Final: …" plus "Proposed result: …" with Confirm or Fix. Nothing settles without the creator's tap. If the feed is down or there is no final score yet, you settle by hand.
5. **Settle sounds** (win / loss / wash) with a mute button saved on the phone. They play only after a tap and never under reduced motion. The sounds use the shared WebAudio synth in js/shared-s25.js, the partner's League edition copied unchanged (md5 8e463fd88a7a4978a6ab52fb24091a3d). Our own mute, reduced-motion and after-a-tap rules still apply; the shared file has no mute logic.
6. **Settle pop-up** (win / loss / wash), about 2 s. Tap or Esc closes it. It shows the shared SVG memes as an image with their captions: WIN "Called it.", LOSS "Oof.", WASH "Nobody wins. Nobody learns." They last S25.MEME_MS = 2000 ms. If the shared file fails to load, a plain text card shows instead.
7. **Tagline** changes every 2 days (US Eastern midnight, counted from 2026-11-01). It uses one shared list, which for now holds a single neutral line; the old weekly lines were removed.
8. **Reactions** under each bet: 👍 👎 🤪 🔥 😂 🍆. Counts show when above 0, and your own reactions are highlighted. Tap or long-press shows who reacted. Watchers see counts only.
9. **Bet card grid:** 1 column under 700 px, 2 from 700 px, 3 from 1400 px, the same breakpoints as the partner site.

10. **Help: "How your queue works"** (Draft Room text, Paul approved). It sits in the Managers card of help.html, and the text is exactly what draftroom-notes/s25-setup/HELP-QUEUE.md gives.
11. **League photo** (Draft Room photo hook). The optional photo from setup (`meta.settings.photo`, checked to be a JPEG data URL) is used as the banner when the commissioner hasn't set one. It is applied as a CSS background only, and anything else falls back to the default banner. *It needs the Draft Room s25 core.js, which keeps `settings.photo`. The core.js in this copy still drops it.*
12. **Funnier power rankings.** Light, kind one-liners were added to the power-ranking recap lines (js/power-gen.js), adapted from draftroom-notes/s25-setup/HUMOR-LEAGUE.md. Every fact, number, grade and sentence count is unchanged: 4-sentence recap, 10-sentence deep dive, grades A+ to D.
13. **Tab bar wraps; no sideways scrolling.** The tabs sit in rows of equal-width buttons: 3 per row at 360px and below, 4 per row at 361-559px, and from 560px one row when the 10 tabs fit (they wrap whenever they don't), the same as the partner site. Every tab is visible, each tap is at least 44px, and labels are never cut off. Below 760px the bar no longer sticks to the top, because it is 3-4 rows tall.

Shared spec: league-site-work/s25-autosettle-spec.md.

## League patch on the merged s25 (s25-league-links)
- **"Your links" for the commissioner** (Draft Room LINKS-HOOK). league.html loads js/links-card.js after ui.js. The League header shows a 🔗 Your links button next to Change photo, for the commissioner only (UI.isCommish). It opens the shared "Save these links" sheet; the links come only from this device, and secrets stay after the #. Managers and watchers don't see the button, and a forced tap opens nothing. league.html carries the sheet and .lcbtns rules inline, because css/app.css is not loaded on the League page.
- **Meme pop-ups shelved** (same on the partner site). One switch in js/league-bets.js, `POPUPS=false`, means no pop-up or meme ever shows. Settle sounds and the mute toggle work as before. js/shared-s25.js is unchanged.
- **Equal-size bet cards.** The grid stretches the cards in each row to the same height, and every card has min-height 220px. Each card is a flex column with a spacer, so notes, buttons and reactions sit at the bottom and line up across a row. Long bet text is clamped to 3 lines, with a "more" / "less" button (at least 44px, aria-expanded, aria-controls) that appears only when the text is cut. The partner site has no card-height or clamp rules (checked owes_s25b_upload and audit), so these values are ours: 220px, 3 lines, "more" / "less".
